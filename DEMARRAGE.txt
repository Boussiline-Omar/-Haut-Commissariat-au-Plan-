                           🔌 COMMENT ÇA MARCHE
═══════════════════════════════════════════════════════════════════════════════

Au démarrage du dashboard:
  1. Le frontend charge
  2. initDashboard() s'exécute
  3. Appel fetch() → GET /segmentation/regions
  4. Appel fetch() → GET /stats/dashboard
  5. Les données remplissent le formulaire et les graphiques
  6. Tout est dynamique et en temps réel!

Quand l'utilisateur calcule un score:
  1. Clique "Calculer le score"
  2. runSim() s'exécute
  3. Appel fetch() → POST /predict/individu
  4. Backend exécute XGBoost
  5. Retourne classe + probabilités
  6. Affichage du résultat immédiat

═══════════════════════════════════════════════════════════════════════════════
                          ❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problème: Port 8000 déjà utilisé
Solution: python run_server.py 8001

Problème: "ModuleNotFoundError: No module named 'fastapi'"
Solution: pip install -r requirements.txt

Problème: "CORS policy" error
Solution: CORS est configuré, essayez Ctrl+Shift+R pour refresh forcer

Problème: Les données ne se chargent pas
Solution: 
  1. Vérifiez que le backend démarre
  2. F12 → Network tab
  3. Vérifiez les requêtes API (200 OK?)
  4. Consultez CONNECTION_STATUS.md

Plus d'aide: consultez INTEGRATION_GUIDE.md
